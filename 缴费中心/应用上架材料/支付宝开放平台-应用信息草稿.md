# 支付宝开放平台 · 创建应用信息草稿（班级缴费中心）

> 用途：在 [支付宝开放平台](https://open.alipay.com) 控制台「创建应用」时照抄/取材。
> 以开放平台当前页面提示为准，本文为草稿与口径参考。

---

## 一、创建步骤速览

1. 登录开放平台 → 控制台 → **创建应用**（个人账号即可创建并使用**沙箱环境**验证全流程）。
2. 填写应用信息（见下节草稿）→ 上传应用图标：**`缴费中心/图标/应用图标_1024.png`**。
3. 创建后进入应用详情：
   - 「开发设置」→ 接口加签方式：**公钥模式 / 证书模式（RSA2）**，用平台**密钥工具**生成商户私钥与公钥；
   - 把**商户私钥**填入 `缴费中心/config.json`（参照 `config.json.example`，私钥只存服务端）；
   - 沙箱环境网关默认 `https://openapi-sandbox.dl.alipaydev.com/gateway.do`（以沙箱页显示为准）。
4. 「产品绑定」→ 绑定 **当面付**（预付线下收款码场景，`alipay.trade.precreate` 返回二维码）或**手机网站支付**。
5. 沙箱钱包（开放平台提供沙箱版支付宝 App）扫码完成真实签名链路验证。
6. 正式收款需**企业 / 个体户主体签约**对应产品；个人主体在沙箱内完成毕业设计演示即可。

## 二、应用信息草稿

| 字段 | 建议填写 | 说明 |
| --- | --- | --- |
| 应用名称 | **班级缴费中心** | 与系统内名称一致 |
| 应用图标 | `缴费中心/图标/应用图标_1024.png` | 方形 PNG、≤1MB（实际约 142KB）；直角原图，平台自动裁圆角 |
| 应用简介 | 面向高校班级的团费、班费收缴与收支公示微应用：费项发布、名单管理、催缴提醒、电子凭证、账本公示，支持支付宝当面付与异步对账。 | 控制台对简介有字数上限，超出可删「支持…」后半句 |
| 应用简介（短版） | 高校班级团费班费收缴与收支公示工具 | 备用 |
| 官网 / 授权回调地址 | 本地演示可留空或填部署地址 | 沙箱阶段非必填 |
| 接口内容（加签后绑定） | `alipay.trade.precreate`（当面付）、`alipay.trade.query`、异步通知 `notify_url` | 与 pay_server 已实现的三个端点一一对应 |

## 三、图标使用说明

- 设计概念「**藏青金 · 班徽硬币**」：深藏青→宝蓝渐变方底 + 金色硬币（¥）+ 细金环 + 四隅证书角饰 + 底部「班缴」金线托带——与系统「川大·藏青金」设计语言同源，**完全原创**，不含支付宝官方商标元素（合规）。
- 交付物（`缴费中心/图标/`）：
  | 文件 | 用途 |
  | --- | --- |
  | `应用图标_1024.png` | **开放平台上传用**（1024×1024 方形） |
  | `应用图标_512.png` / `应用图标_300.png` | 文档 / 界面 / 小尺寸场景 |
  | `应用图标.svg` | 矢量源文件（favicon 与无损缩放） |
  | `圆角预览_512.png` | README / 答辩 PPT 展示预览 |
  | `render_icon.py` | 渲染脚本（Pillow，可复现、可改色） |

## 四、沙箱联调口径（答辩可讲）

1. 沙箱内会分配独立的**沙箱 appId / 沙箱买家账号 / 沙箱网关**，与正式环境完全隔离；
2. `pay_server.py` 检测到 `config.json` 里 appId + 私钥齐备且 `pycryptodome` 可用，自动从 HMAC 演示签名切换为 **RSA2(SHA256withRSA) 真实签名**，调用当面付 precreate 拿到沙箱二维码；
3. 支付结果经**异步 notify** 回调，服务端验签、幂等入账，前端 2 秒轮询呈现「已验签」——与生产链路完全一致，仅换了网关地址与密钥；
4. 沙箱流水可在开放平台「沙箱账单」与 `GET /api/pay/reconcile?date=YYYY-MM-DD` 双向核对。

## 五、合规提醒

- 不得在应用名 / 图标 / 简介中使用「支付宝」商标图形（文字描述用途可以）；
- 真实收取班费团费前，确认资金主体（学校对公 / 班级法人或经办教师）与学校财务制度；
- 商户私钥泄露 = 资金风险：只存服务端、不入代码库、不入前端、不进截图。
