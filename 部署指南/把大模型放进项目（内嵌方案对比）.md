# 把大模型"放进项目里"：三种做法与真实代价

> 结论先说：**能内嵌，但"内嵌"有三种完全不同的含义**。现在系统默认走的是第 ③ 种（零配置自动接入），
> 想要"整个文件夹自带 AI、拷给别人也能用"，用第 ② 种（把 Ollama 与模型放进项目文件夹）。
> 第 ① 种（把模型权重塞进网页里）技术上可行，但有三个硬限制，不建议作为默认方案。

---

## 三种方案对照

| | ① 权重嵌进网页（WASM/WebGPU 小模型） | ② 引擎与模型放进项目文件夹（推荐） | ③ 零配置接入本机服务（已默认实现） |
| --- | --- | --- | --- |
| 用户要不要装东西 | 不要 | 不要（文件夹里已带） | 要装过 Ollama（**你机器上已装**） |
| 要不要填配置 | 不要 | 不要 | **不要**（打开即自动接入；没有则降级为离线模板） |
| 打开方式限制 | **必须用 HTTP 打开**：`file://` 双击时浏览器禁止读取本地模型文件 | `file://` 双击可用 | `file://` 双击可用 |
| 体积 | 项目 +300MB～1GB（0.5B 级量化模型） | 项目 +2～5GB（引擎约 1GB + 模型按需） | 项目不变（模型在系统盘外，如 `E:\OllamaModels`） |
| 生成质量 | 弱：0.5B 级模型写中文通知/日报常跑题 | 好：3B/7B 与现在完全一致 | 好：3B/7B |
| 速度 | 无 GPU 时 WASM 约 2～6 字/秒；WebGPU 快些但不稳 | 你机器上 3B 约 1.5 秒/次（已实测） | 同 ② |
| 适合 | 想要"零依赖纯网页 Demo"的加分点 | **对外交付/拷贝给别人/答辩演示自带 AI** | 自己电脑上用（现状） |

---

## ② 怎么用（文件夹自带 AI）

目录约定（放好就行，脚本自动识别）：

```
班级管理系统/
├── 启动（含AI）.bat          # 双击这个（见下）
├── 工具/ollama/ollama.exe    # ← 放便携版 Ollama 引擎（可选）
├── 模型/                     # ← 放模型文件（可选）
└── index.html
```

`启动（含AI）.bat` 做三件事，顺序是：

1. **找引擎**：`工具\ollama\ollama.exe` → 系统 PATH 里的 `ollama` → 默认安装路径（`%LOCALAPPDATA%\Programs\Ollama\ollama.exe`）。找到哪个用哪个。
2. **定模型目录**：项目里有 `模型\` 就用它（`OLLAMA_MODELS` 指向项目内，**整个文件夹可整体拷贝**）；没有就沿用你系统里已设的目录（不会覆盖）。
3. **起服务 + 打开系统**：11434 已在运行就跳过；否则最小化窗口启动服务，等服务就绪后用默认浏览器打开 `index.html`。打开后**不需要任何 AI 配置**——系统会自动探测并接入，顶部会显示「模型已就绪 · 本地 Ollama · qwen2.5:3b（自动接入，无需配置）」。

只想自查、不想启动任何东西：

```bat
启动（含AI）.bat check
```

会打印：找到的引擎路径、模型目录取值、11434 是否在监听、已安装模型列表。

**把模型拷进 `模型\`** 的做法（便携化，整包带走）：

```bat
rem 在项目根目录执行：把需要的模型拉进项目内目录
set OLLAMA_MODELS=%CD%\模型
ollama pull qwen2.5:3b
```

之后把整个 `班级管理系统` 文件夹拷到别的机器（同样装有 Windows + 显卡驱动），双击 `启动（含AI）.bat` 即可自带 AI 运行。
> 注意：`模型\` 与 `工具\` 属大文件，**不要放进取软著/论文的材料目录**，也不要提交到代码仓库；对外交付时单独压缩打包即可。

## ① 为什么不做成默认（技术真相）

把模型跑在网页里（如 `transformers.js` / `wllama` 这类 WebAssembly 方案）本身是可行的，但对本系统有三个硬伤：

1. **双击打开会失败**：浏览器不允许 `file://` 页面向本地文件发 `fetch`（CORS）。我们的系统主打"双击 index.html 就能用"，
   一旦走这条路就必须改用 `python -m http.server` 之类的本地服务打开，或者给浏览器加 `--allow-file-access-from-files` 启动参数——
   与"零部署"的定位冲突。
2. **体积**：0.5B 级模型 int4 量化后约 300～600MB，加上 WASM 运行时，项目从几 MB 变成几百 MB 的"大软件"。
3. **质量与速度**：0.5B 级模型写"通知/日报/简报"这类中文长文本很容易跑题；无 GPU 时 WASM 推理约每秒几个字，
   演示时会明显卡顿。而 3B 在本机 GPU 上单次约 1.5 秒、质量够用。

如果只是想在答辩里展示"连模型都嵌在网页里、零安装"，可以把它作为一个**可选插件**加进来（挂一个按钮，加载 0.5B 模型做"离线小助手"），
但不建议替换掉现在的本机 Ollama 方案。

## 与软著 / 答辩口径的关系

- AI 始终是**可选插件**：不配置也能用全部功能（离线模板 + 政策资料检索兜底）。
- **数据不出校**：走本地 Ollama 时，学生姓名与成绩都不离开本机；走云端厂商时，发送前自动脱敏。
- 内嵌的是**引擎与模型文件**，不是"把数据传出去"；对外交付时一句话说明即可：
  "系统自带可选的本地大模型能力，无网络、无密钥、数据不出本机也能生成值班日报与通知草稿。"
