# 个人工具：教务 JSON → 系统导入 CSV

这是一个**放在你本机、只在你本机跑**的数据转换小工具，用来把你自己从教务接口拉到的
成绩 / 课表 JSON，转成「班级管理系统 → 数据管理 → 教务数据导入」能直接导入的 CSV。

> **它不做的事**：不联网、不登录、不猜验证码、不保存任何账号密码。
> 拉数据那一步由你在自己的环境里完成（用你手上的教务接口客户端，例如 `zfn_api`），
> 本脚本只读你给的 JSON 文件、只写本地 CSV。班级管理系统本身也**不接入任何校外系统**，
> 仍然只走"粘贴/选择 CSV → 预览 → 导入"这一条路——论文、软著、对外介绍里的口径也是这个，
> 不需要改。

---

## 一、三步用法

### 第 1 步：在你的环境里导出 JSON

用你已有的教务接口客户端拉一次数据，把结果写成 JSON 文件即可（就在你自己的脚本里加三行）：

```python
import json

result = stu.get_grade(2025, 1, use_personal_info=True)   # 成绩：年份 + 学期；只填年份取全年
# result = stu.get_schedule(2025, 1)                      # 课表

with open("成绩.json", "w", encoding="utf-8") as f:
    json.dump(result, f, ensure_ascii=False, indent=2)
```

> 账号密码只在你自己脚本里输入，**不要写进任何会提交、上传或分享的文件**；
> 学校系统的登录凭据也不要交给任何第三方工具。

### 第 2 步：转换成导入 CSV

```bash
cd 个人工具

# 成绩（自动判断类型与字段；结果写入 成绩导入.csv）
python 教务JSON转导入CSV.py 成绩.json

# 成绩接口不返回学号时，补上学号与姓名
python 教务JSON转导入CSV.py 成绩.json --student-no 2025990401001 --name 林一舟

# 课表
python 教务JSON转导入CSV.py 课表.json --kind 课表

# 按学年学期分组的导出（一个 JSON 里多个列表）→ 合并转换
python 教务JSON转导入CSV.py 成绩.json --all-lists

# 不确定 JSON 里的结构：先看有哪些列表
python 教务JSON转导入CSV.py 成绩.json --list
```

跑完会打印：**数据来源 / 识别类型 / 字段对应关系 / 可导入行数 / 涉及学期 / 跳过的行及原因**。
对照"字段对应"检查一眼，识别错了就加 `--map` 指定，例如：

```bash
python 教务JSON转导入CSV.py 成绩.json --map 科目=kcmc --map 分数=zpcj
```

### 第 3 步：在系统里导入

1. 打开系统 → **数据管理** → **教务数据导入（成绩单）** 或 **（课表）**
2. 点「选择文件」选生成的 CSV（或直接用文本编辑器打开 CSV 全选复制，粘贴到文本框）
3. 点**预览**：确认"可导入 N 条 / 错误 0 条"，再看一眼学期与分数
4. 点**导入**

覆盖规则（重复导入不会产生重复数据）：

| 类型 | 覆盖键 |
| --- | --- |
| 成绩 | 学号 + 科目 + 考试名称 + 学期 |
| 课表 | 班级 + 星期 + 节次 + 学期 |

所以每学期从教务重新同步一次，直接再导一遍即可。

## 二、字段与学期口径

**输出列（固定，不要改列名）**

```
成绩：学号,姓名,科目,考试名称,分数,学分,课程性质,学期
课表：班级,星期,节次,课程,教师,地点,学期
```

**必填**：成绩的 学号 / 科目 / 考试名称 / 分数；课表的 班级 / 星期 / 节次 / 课程。
成绩的学期留空会归入系统当前学期，所以建议转换时确保学期能识别出来。

**学期写法**：统一归一化成系统内部键 `2025-2026-1`（2025-2026 学年第一学期）。
下面这些写法都能认：

| 教务里的写法 | 归一化结果 |
| --- | --- |
| `2025-2026-1` / `2025—2026-1` | `2025-2026-1` |
| `2025-2026学年第一学期` | `2025-2026-1` |
| `2025-2026第一学期` | `2025-2026-1` |
| 学年 `2025` + 学期 `2` | `2025-2026-2` |
| 学年 `2025-2026` + 学期 `一` | `2025-2026-1` |

**自动识别的字段名**（中英文都认，可 `--map` 覆盖）：

- 学号：`学号` / `xh` / `studentNo`；姓名：`姓名` / `xm`
- 科目：`科目` / `课程名称` / `课程名` / `kcmc` / `courseName`
- 分数：`总评成绩` / `成绩` / `分数` / `cj` / `score`（也认 `pscj` 平时、`qmcj` 期末）
- 学分：`学分` / `xf`；性质：`课程性质` / `课程属性` / `kcxzmc`
- 学期：`学期` / `学年学期` / `term`；或 `学年 xnm` + `学期 xqm`
- 课表：`星期 xqj`、`节次 jcs`、`教师 jsxm`、`地点 cdmc`、`班级 jxbmc/bjmc`

## 三、常见问题

| 现象 | 处理 |
| --- | --- |
| 提示"没有学号" | 成绩接口常不返回学号，加 `--student-no 学号 --name 姓名` |
| 提示"教务标注为小学期（xqm=3）" | 系统只有两个学期，按需要加 `--xqm3 1`（归第一学期）或 `--xqm3 2` |
| 分数是"优 / 良 / 中 / 及格 / 不及格" | 自动按参考分 95/85/75/65/55 计入，并在提示里列出；介意的科目请手工改 CSV 后再导 |
| 课表没有班级字段 | 加 `--class 计科20252302班`（只导本班就填本班） |
| 记录里没有学期信息 | 加 `--term 2025-2026-1` 兜底；或如果是按学期分组的 JSON，用 `--all-lists` 自动从分组名取学期 |
| 同一批数据里字段名不一致 | 已自动兼容（如一半记录用 `课程名`、一半用 `kcmc`），无需处理 |
| 只有学年没有学期 | 会跳过并提示，用 `--term` 或 `--xqm3` 明确口径 |
| 平时/期末想分开导入 | 加 `--split-exams`，会额外生成"平时成绩""期末成绩"两行（配合系统里的总评合成使用） |
| 导入时提示"学号不存在于系统中" | 该学生不在系统的班级名单里，先在「学生管理」导入名单或手工添加 |

## 四、边界与风险（请自己把握）

1. **这是个人离线工具，不属于系统功能。** 班级管理系统不会、也不应该内置任何对学校系统的登录或抓取——
   一旦内置，系统就不合规、也不可对外推广了。所以这条路是"你自己拉 → 转换 → 导入"。
2. **接口客户端是第三方逆向实现**，不是学校官方提供的接口。学校教务改版、加验证码策略、
   或改成统一身份认证（CAS）后才可登录时，它可能失效——用不了就回到"教务系统里导出 Excel/CSV → 导入"，
   系统的导入器同样认（列名可以是教务导出的中文表头）。
3. **账号安全**：把学号密码交给任何第三方库/脚本之前，先确认来源可信；不要在公共电脑上保存；
   频繁自动登录可能触发学校的风控或账号锁定，按需手动跑一次即可，不要做成定时任务天天跑。
4. **只导本人数据或你负责的班级数据**（辅导员/教师场景）。同学的成绩属于个人信息，不要收集、传播或另作他用。
5. **不要把生成的 CSV 直接发到群里/上传网盘**——里面是姓名+学号+成绩，属于个人信息。

## 五、先用样本数据试一遍（不用真实账号）

`样本数据/` 里放了 4 个模拟各类教务导出结构的 JSON，可以先把流程跑通、确认 CSV 长什么样：

```bash
python 教务JSON转导入CSV.py 样本数据/样本A-中文键.json --list
python 教务JSON转导入CSV.py 样本数据/样本A-中文键.json            # 中文表头，最普通的一种
python 教务JSON转导入CSV.py 样本数据/样本B-正方原生键.json --split-exams   # 正方原生字段 + 平时/期末拆分
python 教务JSON转导入CSV.py 样本数据/样本C-嵌套结构.json --all-lists      # 按学年学期分组的多个列表
python 教务JSON转导入CSV.py 样本数据/样本D-课表.json --kind 课表          # 课表
```

四个样本跑出来的行数分别是 3 / 6+1 跳过（小学期）/ 3 / 3；
导入时请用系统里真实存在的学号或班级，否则会被"学号不存在于系统中"挡下（这是预期的校验）。
