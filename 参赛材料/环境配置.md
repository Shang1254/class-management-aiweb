# 环境配置说明

## 一、总体要求

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 运行时 | **无 Node.js、无后端、无数据库、无构建** | 纯静态站点；全部逻辑在浏览器执行 |
| 浏览器 | Chrome / Edge / Firefox 近两年版本 | 需支持 ES2020、localStorage、`crypto.subtle`、`fetch` |
| 磁盘 | ~10 MB（项目文件） | 演示数据存浏览器 localStorage，约 1–2 MB |
| 网络 | **可完全离线运行** | 仅 AI（公网模型）、天气、ECharts CDN 需要网络，均有降级方案 |

## 二、启动方式

```bash
# 方式一（推荐）：静态服务器
cd 班级管理系统
python -m http.server 8899
# http://127.0.0.1:8899
```

```text
方式二：直接双击 index.html（file:// 协议）
- 除天气/ECharts CDN 外功能全部可用
- 本机 Ollama 需设置 OLLAMA_ORIGINS=*（见第四节）
```

> 首次开启时自动写入演示数据；「管理员 → 侧边栏 → 重置示例数据」可随时复位。

| 依赖 | 形式 | 用途 | 断网表现 |
| --- | --- | --- | --- |

## 四、可选：本机大模型（Ollama）

**目的**：AI 能力全程在本机推理，学生数据不出校，零调用费。

1. 安装 Ollama（Windows 安装包，免管理员）：<https://ollama.com>
2. 拉取模型（任选，3b 优先）：
   ```bash
   ollama pull qwen2.5:3b     # 约 1.9GB，CPU 可跑
   ollama pull qwen2.5:7b     # 约 4.7GB，效果更好（有 GPU 推荐）
   ```
3. 保持默认端口 **11434**；系统在登录后自动探测并接入（`AI.autoDetect`），界面显示「已接入本机模型」。
4. 若从 `file://` 打开且提示跨域：设置环境变量并重启 Ollama：
   ```bat
   setx OLLAMA_ORIGINS "*"
   ```
5. 可选：`OLLAMA_MODELS` 指定模型目录（避免占用 C 盘）：
   ```bat
   setx OLLAMA_MODELS "E:\OllamaModels"
   ```

**未安装 / 未启动 / 断网时**：AI 相关功能自动降级为离线规则模板（通知起草/学情简报/出题/值班日报/帮扶方案均有内置模板），界面明确标注「离线模板」，不影响演示与日常使用。

## 五、可选：公网大模型（不推荐用于含真实数据的场景）

登录 → AI 助手 → 设置：选择厂商（智谱/DeepSeek/通义/Kimi/硅基流动/火山方舟）或「自定义」OpenAI 兼容端点，填入 Base URL、模型名、API Key。

- Key 仅保存于本机 localStorage（`cms_ai_config`），不上传、不进代码；
- 默认开启**脱敏**（姓名→学生A、手机号→138****0000、身份证隐去）；
- 任何写操作（发布通知/测验等）均需人工确认后执行。

## 六、可选：缴费中心（支付宝沙箱，演示用）

缴费中心是独立微应用，默认使用内置演示收银台，**无需任何配置**即可演示完整支付闭环。

如需真实沙箱签名链路（答辩加分项）：

1. 安装 Python 依赖：`pip install pycryptodome`
2. 支付宝开放平台 → 沙箱 → 接口加签方式 → 系统默认密钥 → 查看，取「应用私钥（非 JAVA/PKCS#1）」与「支付宝公钥」
3. 填入 `缴费中心/config.json`（模板见 `config.json.example`）：
   ```json
   "app_id": "9021xxxxxxxxxxxx",
   "private_key": "（应用私钥，单行）",
   "alipay_public_key": "（支付宝公钥）"
   ```
4. 双击 `启动缴费签名服务.bat`（端口 8818），看到 `alipay-sandbox（RSA2 真实签名）` 即成功；
5. `沙箱自检.bat` 可一键验证下单链路（返回真实沙箱二维码）。

> 密钥只存本机服务端 config.json，不进前端、不进仓库（已加入 .gitignore）。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 打开后数据是旧的/空白 | 管理员 → 重置示例数据；或浏览器控制台 `localStorage.clear()` 后刷新 |
| AI 一直显示「离线模板」 | 确认 Ollama 在运行（`http://localhost:11434` 可访问）、模型已 pull |
| file:// 下 Ollama 报跨域 | 设置 `OLLAMA_ORIGINS=*` 并重启 Ollama |
| ECharts 图表不显示 | 断网属正常，已自动降级 CSS 图表 |
| 端口 8899 被占用 | 换端口（`python -m http.server 8900`）或结束占用进程 |
