## 分镜逐字稿

### 0:00–0:40 问题与定位

**画面**：桌面 → 双击 `index.html` → 登录页（校园实景）。
**旁白**：
> 「高校班级管理有个断层：教务系统管成绩，学工系统管事务，但辅导员每天要回答的问题——今天谁没打卡、谁该谈话、谁材料没交——仍然靠手工表格。我做的班级管理系统，就是补上班级层这最后一公里。它不用服务器、不用数据库，双击打开就能用；AI 是它的核心能力，优先跑在本机模型上，学生数据不出校，断网也能用。」

**字幕**：纯前端 · 零部署 · AI 核心能力 · 数据不出校

### 0:40–1:30 登录与三级权限

**画面**：登录页展示账号提示 → 输入 `judge / 123456` → 侧边栏展开（21 个菜单）→ 悬停「成绩管理」「请假审批」。
**旁白**：
> 「系统有三类角色、两条业务线。管理员管全局；任课教师走教学线——成绩、作业、测验；辅导员走学工线——请假、奖助、健康日报。兼任授课的辅导员可以同时打开两条线，这就是评审账号 judge。页面内还有第二道权限校验，直接改地址栏也进不去不该进的页面。」

**字幕**：角色 × 岗位双维度 · 兼任授课开关 · 敏感信息分级

### 1:30–2:30 仪表盘与学情

**画面**：仪表盘 → 日历牌 Hero → 统计卡数字滚动 → 待办条 → 今日课程 → 点击「未报健康日报」跳转。
**旁白**：
> 「辅导员打开就是一张工作台：今天出勤率、健康日报填报率、校外动向人数、待审批请假、学业预警，全部自动汇总。点任何一条待办直接跳到处理页面。日历牌带农历、节气和法定节假日，请假审批会自动按工作日联动考勤——跨国庆只算工作日。」

**字幕**：一屏看清「谁异常、谁该谈话」· 请假 → 考勤自动联动

### 2:30–4:00 AI 助手（重点段落）

**画面**：AI 助手 → 「值班日报」→ 点击生成（展示工具规划与结果）→ 处理入口按钮 → 切「帮扶跟踪」→ 生成对比 → 切「通知起草」→ 生成并发布 → 断网演示离线模板。
**旁白**：
> 「AI 不是聊天框，是三个有工具的智能体。值班日报：模型先规划要查哪些数据——待审批请假、体温异常、出勤趋势、奖助节点——系统只读执行，再汇总成日报，每条都带处理入口。帮扶跟踪：自动找风险学生，两次运行还能对比谁改善了、谁是新进的。通知起草：生成草稿，人工确认后一键发布。这里用的是本机 qwen2.5 模型，三秒出日报；把模型停掉，系统自动切换到离线规则模板——同样的结构，永远不会没有结果。」

**字幕**：工具白名单 · 只读 · 人在环 · 离线兜底

### 4:00–5:00 成绩分析与学业预警

**画面**：成绩管理 → 批量录入（Enter 跳格）→ 总评合成 → 成绩分析图表（ECharts）→ 学业预警三视角。
**旁白**：
> 「教学线这边：批量录入支持回车跳格，学分选填；总评按平时六成、期末四成自动合成，绩点按真实学分加权。成绩分析是 ECharts 图表，断网会自动降级成手绘风格的 CSS 图表。学业预警一套规则三个视角：学生本人收到预警卡和补救建议，辅导员看到帮扶台账，任课教师看到课堂关注名单。」

**字幕**：批量录入 · 总评/绩点 · 三视角预警

### 5:00–5:40 移动端 / 深色主题 / 断网降级

**画面**：浏览器切 375px 宽度（响应式）→ 深色主题切换「日/月」→ 断网刷新（图表降级、天气隐藏、AI 离线模板）。
**旁白**：
> 「移动端自适应，侧边栏收成抽屉；深色主题一键切换。断网时：图表降级、天气隐藏、AI 走离线模板——演示和机房环境都不会翻车。」

**字幕**：响应式 · 深色主题 · 断网可用

### 5:40–6:30 架构与 AI 技术

**画面**：切到技术文档 PDF 第 5 页（架构图）→ 第 11 页（AI 方案）→ 快速滚动到缴费中心截图。
**旁白**：
> 「架构上分五层：store 是唯一数据出入口，所有增删改自动写审计日志；auth 负责权限和数据范围；ui 是复用组件；pages 是页面注册表；ai 是服务层。AI 方案三句话：多厂商适配、零配置接本机 Ollama、模型只调白名单工具且所有写入人工确认。另外集成了一笔缴费微应用——团费班费收缴、支付宝沙箱真实 RSA2 签名链路、只读的智能审计，宿主只通过契约桥传身份和名册。」

**字幕**：五层架构 · 本地优先 AI · 独立微应用契约挂接

## 录制操作清单

1. 提前启动 `python -m http.server 8899`；如演示本机 AI，先 `ollama run qwen2.5:3b 你好` 预热。
2. 浏览器 1920×1080、100% 缩放；关闭无关标签与通知。
3. 每段先录画面操作再配音（或边操作边讲），留 1 秒静帧便于剪辑。
4. 导出：H.264 / MP4 / 1080p / 帧率 30 / 码率 6–8 Mbps / 采样率 48kHz。
5. 剪辑后核对：总时长 6–7 分钟；无真实姓名/手机号；字幕与操作同步。
