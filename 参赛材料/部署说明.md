# 部署说明（静态部署 / GitHub Pages / Netlify）

> 本项目为纯静态站点：**无构建、无后端、无环境变量**。演示数据在浏览器本地生成，服务器只需托管静态文件。
> ⚠️ 部署前必须确认：仓库与站点使用的均为**合成演示数据**（本仓库已合成化，见 `开发过程说明.md`）。

## 一、GitHub Pages（推荐，零成本）

1. 仓库已存在：`https://github.com/Shang1254/class-management-local`（Public）
2. 确认 `index.html` 位于仓库根目录（本仓库即如此）
3. 仓库 → Settings → Pages：
   - Source: `Deploy from a branch`
   - Branch: `main` / 目录 `/(root)` → Save
4. 等待 1–2 分钟，访问：
   - `https://shang1254.github.io/class-management-aiweb/`
5. 首次访问后等待自动生成演示数据，登录 `judge / 123456` 验证

### 部署后自测清单
- [ ] 登录页正常显示（校园图/回退渐变色均可）
- [ ] `judge / 123456` 登录成功，侧边栏 ≥20 个菜单
- [ ] 仪表盘统计卡有数据；学生管理列表 75 人（专升本班 31 人）
- [ ] 学生名单中无真实姓名/学号（抽查：应全部为 `202599…` 虚构学号段）
- [ ] 成绩分析图表可交互（断网时为 CSS 图表）
- [ ] AI 助手可打开；未配置模型时显示「离线模板」且能生成草稿
- [ ] 缴费中心（辅导员菜单）可打开，发布费项/演示收银台可跑通
- [ ] 移动端窄屏（375px）无横向滚动溢出

## 二、Netlify（备选）

1. 登录 <https://app.netlify.com> → Add new site → Import an existing project
2. 选择 GitHub 仓库 `Shang1254/class-management-aiweb`
3. 构建设置：
   - Build command：**留空**
   - Publish directory：**`.`**（仓库根目录）
4. Deploy → 得到 `https://<随机名>.netlify.app`
5. 按上节清单自测

## 三、其他静态托管（学校服务器 / Nginx）

```nginx
server {
    listen 80;
    server_name your-domain.example;
    root /var/www/class-management;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

> 因使用 Hash 路由（`#/page`），无需 rewrite 规则；`try_files` 仅为兜底。

## 四、注意事项

| 项 | 说明 |
| --- | --- |
| 数据隔离 | 每个浏览器/设备独立存储（localStorage），互不干扰；换设备需重新生成演示数据 |
| 更新版本 | 修改任何 JS/CSS 后递增 `index.html` 中的 `?v=` 版本号（防缓存，项目铁律） |
| 隐私 | 公开站点只放合成数据；真实数据不要部署到公网 |
| 缴费中心 | 内置演示收银台无需配置即可用；真实支付宝沙箱需在本机运行 `pay_server.py`（静态托管环境不适用） |
| AI | 公网模型需在本机设置里填 Key（Key 只存浏览器）；本机 Ollama 仅在本地运行时可用 |
