# 班级管理系统（AI 增强 · 纯前端 Web 应用）

> **一句话定位**：面向高校班级的「教学 + 学工」双线管理微应用——不依赖后端与数据库，双击 `index.html` 即可运行；内置 AI 助手与三个智能体（值班日报 / 学业帮扶 / 学生办事），支持本机 Ollama 零配置接入，断网自动降级离线模板。

**参赛信息**：2026 第九届传智杯全国大学生数智创新与 AI 应用大赛 · AI WEB 网页开发挑战赛 · **B 组**（个人参赛）
**团队信息**：商子轩 · 武汉晴川学院 · 计算机学院 · 计算机科学与技术（专升本）· 2025 级 · 学制二年制

## 一、问题背景

高校班级管理存在三个断点：

1. **校级平台管不到班级层**：教务系统管成绩、学工系统管事务，但辅导员「今天谁没打卡、谁该谈话、谁材料没交」仍靠手工表格；
2. **任课教师与辅导员职责不同却共用一套工具**：教学线（成绩/作业/测验）与学工线（请假/奖助/健康/考勤月报）混杂，权限边界模糊；
3. **AI 能力要么缺失，要么依赖公网大模型**：学生数据出校存在合规顾虑，断网即失效。

本系统用**纯前端 + 本地优先**的方式补齐班级层：数据全部存于浏览器 localStorage，AI 优先走本机 Ollama（数据不出校），无模型时自动降级规则模板，保证「永远有结果」。

## 三、10 分钟运行步骤

**零依赖、零安装、零构建**：

```bash
# 方式一（推荐）：任意静态服务器
cd 班级管理系统
python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899

# 方式二：直接双击 index.html（file:// 协议同样可用）
```

首次打开自动生成演示数据（localStorage，约 1–2 MB）。浏览器要求：Chrome / Edge / Firefox 近两年版本。

**可选 AI（本机大模型，数据不出校）**：
1. 安装 [Ollama](https://ollama.com)；
2. `ollama pull qwen2.5:3b`（约 1.9GB，低配可用；7b 效果更好）；
3. 保持服务默认端口 `11434`，系统会自动发现并接入（无需填写任何配置）；
4. 未安装 / 未启动 / 断网时：AI 功能自动降级为**离线规则模板**，并在界面标注「离线模板」。

更细的依赖与离线说明见 [`环境配置.md`](./环境配置.md)；静态部署（GitHub Pages / Netlify）见 [`部署说明.md`](./部署说明.md)。

## 六、数据与隐私说明

- **演示数据全合成**：姓名、学号、手机号、住址、成绩、考勤均为生成数据，与任何真实人员无关；学号段位 `202599xxxxxxx` 为虚构专用段。
- 真实使用场景下：数据仅存于使用者本机浏览器（localStorage），不上传任何服务器；AI 调用默认脱敏，可切换本机模型实现「数据不出校」。
- 公开仓库、文档、视频、截图均使用合成数据；不含真实学生/教师个人信息。
- 第三方依赖：SheetJS（本地内置，解析 Excel）、ECharts（CDN，断网自动降级为自绘 CSS 图表）、Open-Meteo（天气，免密钥，可断网）、校园图片来源为学校官网公开图集（已压缩并剥离 EXIF）。
